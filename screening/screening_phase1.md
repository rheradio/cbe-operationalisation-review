## Criterion codes

### Inclusion (ALL must hold)
| Code | Criterion |
|------|-----------|
| I1 | CBE/CBL paradigm structurally operative |
| I2 | Engineering or STEM higher education |
| I3 | Assessment operationalisation is a primary or substantive secondary contribution |
| I4 | At least one structural element of the competency-assessment chain |
| I5 | Course or programme level with sufficient replicable detail |

### Exclusion (ANY is sufficient)
| Code | Criterion |
|------|-----------|
| E1 | Non-target discipline or population |
| E2 | Workforce/professional-certification "competency" only — no student HE assessment |
| E3 | No assessment design (curriculum mapping, framework, accreditation, perception survey) |
| E4 | Assessment incidental to pedagogical intervention (pre/post scores only) |
| E5 | Standardised/external exam only, no course-level competency disaggregation |
| E6 | Technology tool without specifying the underlying rubric/indicator/alignment structure |
| E7 | Advocacy, conceptual position, or narrative review — no concrete operationalisation |
| E8 | Excluded document type (abstract-only, editorial, book chapter) |
| E9 | Non-English full text |
